Frequently asked questions.

Will it always increase FPS?

No. Systems with avoidable background load or inefficient settings may see a more noticeable change, while optimized systems may see little difference.

Does it support Windows 11?

Yes. The project is intended for supported 64-bit versions of Windows 10 and Windows 11.

Can settings be restored?

Supported changes can be reverted through the restore function or a Windows restore point.
